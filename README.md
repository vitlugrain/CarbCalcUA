# CarbCalc UA MVP 0.4

## Головні зміни
- повноцінний щоденник із датами;
- окремі прийоми їжі: сніданок, обід, вечеря, перекус;
- збереження записів щоденника в SQLite;
- підсумок дня у грамах вуглеводів та ХО;
- перегляд історії за календарем;
- видалення запису довгим натисканням;
- збереження рецептів у SQLite;
- розрахунок порції готової страви та додавання її до щоденника;
- «Мій продукт» — введення даних з етикетки та збереження у локальній БД;
- налаштування системи ХО.

## Запуск
```bash
flutter pub get
flutter run
```

## Важливо
Демонстраційна база продуктів поки не є повноцінним медичним довідником. Перед релізом потрібно верифікувати джерела харчових значень, додати версіювання бази та механізм виправлення помилок.

Застосунок не визначає дозу інсуліну і не замінює рекомендації лікаря.
