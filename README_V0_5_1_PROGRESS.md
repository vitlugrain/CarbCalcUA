# CarbCalc UA — MVP 0.5.1 progress

Цей checkpoint продовжує стабілізацію V0.5.

## Зміни
- додано єдиний `FoodCalculationService` для перерахунку `г/мл/шт/порція` у грами та розрахунку вуглеводів/ХО;
- користувацький продукт тепер може одразу мати штрихкод, вагу 1 шт, г/мл та вагу порції;
- збережено принцип: ХО обчислюються за налаштуванням користувача;
- додано тести для конверсії одиниць і відсутніх даних конверсії;
- версію піднято до 0.5.1+3.

## Перед Android-тестом
Потрібно зібрати APK у Flutter-середовищі та перевірити на реальному пристрої: текстовий пошук, кількість, щоденник, камеру, штрихкод, Open Food Facts, локальне збереження та міграцію V0.4.
