# ProDiabet — фінальний звіт імпорту

Статус: **блок завершено**.

Джерела:
- публічна таблиця глікемічного індексу ProDiabet.ua;
- скріншоти калькулятора продуктів з особистого кабінету ProDiabet.ua, надані користувачем.

## Правила імпорту

- ХО з ProDiabet **не зберігаються**: CarbCalc UA розраховує їх самостійно з кількості вуглеводів у фактичній порції.
- Для продукту, який уже є в основній базі, ProDiabet використовується насамперед для **збагачення ГІ**; базові перевірені Б/Ж/В не перезаписуються автоматично.
- Окремі рецептурні або технологічно відмінні позиції зберігаються як окремі продукти.
- Очевидно неузгоджені значення зі скріншотів не виправляються припущенням і не потрапляють до verified-каталогу; вони винесені в `prodiabet_pending_review.json`.
- Повторно надісланий скріншот з 5 позиціями опрацьовано один раз.

## Підсумок останнього пакета скріншотів

- 94 унікальні позиції опрацьовано;
- 27 позицій відповідали наявним продуктам і використані для GI-enrichment;
- 62 нові позиції додані до verified-каталогу;
- 5 позицій відкладені через сумнівні/неузгоджені дані;
- 5 повторно надісланих рядків з дубльованого скріншота не дублювалися в базі.

## Підсумок ProDiabet у репозиторії

- `prodiabet_ua_verified.json` — 38 перевірених standalone-позицій з попереднього етапу, очищених від полів ХО;
- `prodiabet_ua_verified_part2.json` — 62 нові перевірені standalone-позиції останнього пакета;
- разом: **100 standalone ProDiabet-позицій**;
- `prodiabet_gi_enrichment.json` — **33 унікальні наявні продукти CarbCalc UA**, збагачені ГІ/метаданими джерела;
- `prodiabet_pending_review.json` — **5 позицій**, які навмисно не включені у verified-каталоги.

## Відкладені позиції

1. Морква — GI 85: на скріншоті не уточнений стан продукту, тому значення не переноситься на базову сиру моркву.
2. Картопляна запіканка — жир 53 г при 128 ккал: внутрішньо неузгоджено.
3. Капуста білокачанна тушкована — жир 33 г при 75 ккал: внутрішньо неузгоджено.
4. Капуста цвітна — жир 6,1 г для позиції без уточнення способу приготування потребує підтвердження.
5. Капуста цвітна відварна — білок 0 г та енергетична цінність потребують підтвердження.

Додатково для винограду та чорної смородини значення жиру зі скріншота не використано через явну невідповідність калорійності; ГІ та узгоджені поля джерела збережені в enrichment-файлі.

`prodiabet_ua_verified_part2.json` підключений у `scripts/merge_verified_catalogs.py`. `prodiabet_pending_review.json` до злиття **не підключений**.

Після цього блоку наступне джерело для опрацювання: **Торчин**.
