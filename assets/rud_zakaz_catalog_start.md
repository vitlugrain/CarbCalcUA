# ТМ «Рудь» — аудит Zakaz.ua

Статус: активний блок.

## Метод

1. Zakaz.ua використовується для пошуку актуальних SKU, фасувань і товарів, яких може не бути в CarbCalc UA.
2. Для ТМ «Рудь» пріоритетна перевірка nutrition/EAN виконується за офіційним каталогом rud.ua, коли офіційна картка доступна.
3. Перед імпортом кожен SKU порівнюється з `assets/products.json`: exact SKU/EAN, nutrition duplicate, новий продукт або conflict/pending.
4. Не усереднювати конфліктні рецептури; старі та нові SKU з різними Б/Ж/В зберігати окремо або pending.

## Категорії проходу

- заморожені напівфабрикати;
- морозиво;
- заморожені овочі, ягоди та суміші;
- заморожене тісто;
- хлібобулочні вироби;
- сирки;
- масло;
- молочні продукти.
