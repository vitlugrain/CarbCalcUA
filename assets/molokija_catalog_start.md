# Молокія — старт опрацювання каталогу

Статус: ACTIVE

Офіційні джерела:
- https://www.molokija.com/
- https://molokija.com/about
- https://molokija.com/storage/files/produkciya-onovlena-1.pdf
- https://horeca.molokija.com/

Підтверджені актуальні напрями/категорії каталогу:
- молоко та UHT-молоко;
- безлактозне молоко;
- кефір 1,0% і 2,5% у пляшці та плівці;
- білий йогурт, у т.ч. безлактозний, з пробіотиками, по-грецьки;
- солодкі йогурти;
- сметана 15% і 20%;
- вершки;
- айран;
- кисломолочний сир та інші молочні продукти;
- HoReCa-фасування як окреме джерело для перевірки складу/ваги, але не як підстава для створення окремих nutrition-records при однаковій рецептурі.

Поточне правило імпорту:
1. Спочатку звіряти кожен типовий продукт з уже наявною базою CarbCalc UA.
2. Якщо Б/Ж/В збігаються з уже наявним типовим молочним продуктом — зберігати Молокію як бренд/SKU-варіант, без окремого nutrition-record.
3. Якщо рецептура або харчовий профіль відрізняються — створювати окремий verified record.
4. Безлактозні, пробіотичні, функціональні та смакові продукти не зливати зі звичайними лише через однакові Б/Ж/В.
5. Не переносити харчові значення з неофіційних магазинів, якщо їх немає в офіційній картці/каталозі виробника.
6. Якщо офіційне джерело дає склад і вагу, але не дає Б/Ж/В — позицію залишати pending, не оцінювати «на око».

Перший офіційний прохід підтвердив наявність, зокрема:
- Кефір 1,0% питний, пляшка 870 г;
- Кефір 2,5% питний, пляшка 870 г;
- Кефір 2,5% питний, пляшка 250 г;
- Кефір 1,0% у плівці 900 г;
- Кефір 2,5% у плівці 900 г;
- Молоко UHT 3,2% 950 г;
- Молоко безлактозне UHT 2,5% 950 г;
- Молоко 2,5% «До кави» 900 г;
- Молоко безлактозне 2,5% 870 г;
- Сметана 15% і 20% у споживчих та HoReCa-фасуваннях;
- Білий йогурт 1,6%;
- Білий йогурт безлактозний 2,5%;
- Білий йогурт + пробіотики 2,5%;
- Білий йогурт по-грецьки 8%.

Наступний етап: витягнути та звірити точні Б/Ж/В/ккал для споживчих позицій з офіційного каталогу, після чого рознести записи у molokija_verified_*.json / molokija_dedup_review.json / molokija_pending_review.json.
