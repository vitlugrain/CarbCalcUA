# CarbCalc UA MVP 0.5 — Smart Food Search

Checkpoint: український пошук продуктів.

## Що реалізовано

- кількість та одиниця на початку або в кінці запиту;
- українські словоформи для типових харчових запитів;
- нечіткий пошук за токенами;
- окреме ранжування стану продукту: сухий/сирий/варений/свіжий;
- уточнення способу приготування: на воді / на молоці;
- запит `гречка` повертає кілька релевантних варіантів;
- запит `гречка варена на воді` ставить відповідний продукт першим;
- `2 шт печива Марія` розбирається як кількість + одиниця + продукт;
- додані unit-тести для ключових сценаріїв.

## Принцип безпеки

Неоднозначний запит не повинен мовчки перетворюватися на один продукт. Користувач бачить варіанти та підтверджує продукт перед розрахунком.

## Наступний етап

Підключити barcode lookup до того самого `FoodSearchService`, а потім зробити повноцінний екран підтвердження продукту та кількості.
